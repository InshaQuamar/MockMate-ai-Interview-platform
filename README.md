## Run Locally

**Prerequisites:**  Node.js


1. Install dependencies:
   `npm install`
2. Run the app:
   `npm run dev`

## Deploy on Render

You can deploy this app as a static site on Render:

1. Push this project to a Git repository (GitHub, GitLab, etc.).
2. In Render, create a **Static Site** and connect your repo.
3. Use **Build Command**: `npm install && npm run build`
4. Use **Publish Directory**: `dist`
